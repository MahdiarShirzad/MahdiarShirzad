## About Me

I'm a full-stack developer working primarily with TypeScript, React, Next.js, Node.js, Express, and NestJS.

I enjoy taking projects beyond the UI: designing APIs, modeling data, implementing authentication, structuring backend systems, and deploying complete applications on my own infrastructure.

* **Frontend:** React, Next.js, TypeScript, Tailwind CSS, TanStack Query.
* **Backend:** Node.js, Express, NestJS, REST APIs, PostgreSQL, Prisma, MongoDB, Mongoose, OAuth and JWT-based auth.
* **Infrastructure:** Self-managed Linux VPS with Nginx, PM2, SSL, and GitHub Actions CI/CD.
* **Engineering interests:** Backend architecture, authentication, API design, relational data modeling, and deployment.
* **Beyond coding:** Studying Computer Engineering and mentoring developers learning Node.js and Express.

## Goal

Becoming a **Full-Stack AI Engineer / Agentic AI Engineer**: building production-grade web applications where LLM-powered agents, tool calling, and automated workflows are first-class parts of the product, backed by solid backend architecture.

## Current Focus

**RunBolt** — A developer-first workflow automation platform with a visual graph builder, an asynchronous execution engine, and execution history. I built the product's landing experience, design system, and workflow builder UI, and I'm now building its backend with **NestJS, Prisma, and PostgreSQL**.

I'm also deepening my understanding of backend architecture: guards, interceptors, queues, and the engineering decisions that keep applications maintainable beyond their first release.

## Selected Projects

### ⚙️ DevMatrix

**An AI-assisted developer platform: four tools in one project-scoped workspace.**

A Turborepo monorepo with a Next.js frontend and an Express API, built as a complete product and deployed to production.

* **API Playground:** a Postman-style request builder with collections and saved requests, backed by an execution service with SSRF protection, timeouts, and response size limits.
* **AI Debugging Assistant:** analyzes code, explains the problem, and returns a fix with a diff view.
* **Developer Analytics:** GitHub OAuth integration with commit and PR syncing, activity heatmaps, contributor stats, and time-range filtering.
* **SaaS Idea Validator:** AI-driven scoring and analysis of startup ideas.
* Cookie-based JWT auth with automatic token refresh, plus customizable color themes and fonts.

**Stack:** `Next.js` `TypeScript` `Express` `MongoDB` `TanStack Query` `Turborepo`

### 🏭 Foundry

**A product-building workspace that guides founders from first idea to measurable launch.**

An eight-stage platform with a Next.js frontend and a NestJS backend, organized around a shared product anchor so every stage connects to the same product.

* **Stages:** Idea Lab, Market Intelligence, Validation Lab, MVP Studio, Product Roadmap, Launch Center, Feedback Hub, and Founder Analytics.
* Authentication with email verification, password reset, and refresh tokens, enforced by global guards.
* Relational data model with Prisma and PostgreSQL, covering ideas, hypotheses, experiments, features, releases, and feedback.
* **Status:** in active development; auth and the product module are complete and connected end to end.

**Stack:** `Next.js` `TypeScript` `NestJS` `Prisma` `PostgreSQL`

### 🧳 My Trip

**A full-stack flight and hotel booking application.**

Built with a Next.js frontend and a separate TypeScript/Node.js/Express backend.

* MongoDB Atlas and Mongoose for data persistence.
* JWT access and refresh tokens for authentication.
* Arvan Object Storage for file storage.
* Backend deployed on Railway.

**Stack:** `Next.js` `TypeScript` `Node.js` `Express` `MongoDB` `JWT`

[View repository →](https://github.com/MahdiarShirzad/my-trip)

### 🎓 Deep Coding

**An e-learning platform for programming education.**

A Udemy-style platform with separate student, teacher, and admin panels.

* Role-based access control with protect/restrict middleware.
* Admin dashboards powered by MongoDB aggregation pipelines.
* Carts, wishlists, reviews, blog, and book systems.
* File uploads to S3-compatible object storage.
* Frontend on Vercel, backend on Railway.

**Stack:** `React` `Node.js` `Express` `MongoDB` `React Query`

[View repository →](https://github.com/MahdiarShirzad/deep-coding)

### 🌐 Personal Portfolio

My personal website, with a custom administration panel, secure admin login, and animated sections.

* Next.js API routes with MongoDB for contact messages.
* Admin-editable content for projects, skills, resume, and services.
* JWT authentication with httpOnly cookies.
* Self-hosted on a VPS.

**Stack:** `Next.js` `TypeScript` `Tailwind CSS` `GSAP` `MongoDB`
