## About Me

I'm a full-stack developer working primarily with TypeScript, React, Next.js, Node.js, and Express.

I enjoy taking projects beyond the UI: designing APIs, modeling data, implementing authentication, structuring backend systems, and deploying complete applications.

* **Frontend:** React, Next.js, TypeScript, and modern state management.
* **Backend:** Node.js, Express, REST APIs, MongoDB, and Mongoose.
* **Engineering interests:** Backend architecture, authentication, API design, and deployment.
* **Beyond coding:** Studying Computer Engineering and mentoring developers learning Node.js and Express.

## Current Focus

**Runbolt** — Developing the product's landing experience, design system, and motion language.

I'm also continuing to deepen my understanding of backend architecture and the engineering decisions that make applications maintainable beyond their initial release.

## Selected Projects

### 🧳 My Trip

**A full-stack flight and hotel booking application.**

Built with a Next.js frontend and a separate TypeScript/Node.js/Express backend.

* MongoDB Atlas and Mongoose for data persistence.
* JWT access and refresh tokens for authentication.
* Arvan Object Storage for file storage.
* Backend deployed on Railway.

**Stack:** `Next.js` `TypeScript` `Node.js` `Express` `MongoDB` `JWT`
